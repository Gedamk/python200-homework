# Week 11 Pipeline Run Reflection

The pipeline did not run cleanly on the first try. My first run completed the extract and transform tasks, but the load task failed because `AZURE_STORAGE_ACCOUNT_NAME` was missing from my `.env` file. After I added the Azure storage account name, I ran it again and the extract task completed, but the transform task failed because `OPENAI_API_KEY` was missing. I fixed the `.env` file by adding both the OpenAI API key and Azure storage account name, then reran the pipeline successfully. In the Prefect UI, I saw the extract, transform, and load tasks complete, and the logs showed progress every 6 transformed records. If I deployed this pipeline to run daily, I would add a scheduled deployment, alerts for failed runs, and stronger validation for environment variables before the flow starts.
